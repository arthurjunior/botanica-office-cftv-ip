# 08 — Documentação Acadêmica

Pasta destinada à consolidação do trabalho acadêmico de aproximadamente 15 páginas, conforme orientação do professor, utilizando o PMBOK como referencial.

A redação final deverá distinguir dados da proposta, análise do estudante e planos propostos. Conferir as normas de formatação e os requisitos acadêmicos da instituição.
